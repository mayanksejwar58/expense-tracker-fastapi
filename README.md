# Expense Tracker

A full-stack Expense Tracker application built with Python.

## Features

- Secure Authentication
- Dashboard
- Add/Edit/Delete Expenses
- Income Tracking
- Categories
- Monthly Reports
- Analytics & Charts

## Tech Stack

### Backend
- FastAPI
- SQLAlchemy
- PostgreSQL
- JWT Authentication

### Frontend
- Streamlit
